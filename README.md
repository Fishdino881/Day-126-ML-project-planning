# Day-126-ML-project-planning

###  Overview

Day 126 focuses on **Machine Learning Project Planning**, an important step before building any ML system.

Good planning helps in:

* Defining project goals
* Choosing the right dataset and algorithms
* Designing workflows efficiently
* Avoiding future issues during development

---

##  What is ML Project Planning?

ML project planning is the process of organizing all stages of a machine learning project before implementation.

It includes:
- Problem definition
- Data collection strategy
- Model selection
- Deployment planning

---

##  ML Project Workflow

```text id="mlplan1"
Problem Definition → Data Collection → Preprocessing → Model Building → Evaluation → Deployment
```

---

##  Planning Steps

### 1️ Define the Problem

Understand:

* What problem needs to be solved
* Expected output

Example:

> Predict customer churn using historical data.

---

### 2️ Collect Data

Identify:

* Data sources
* Dataset size
* Data quality

---

### 3️ Data Preparation

Plan for:

* Cleaning
* Feature engineering
* Handling missing values

---

### 4️ Select ML Algorithm

Choose based on task:

| Task           | Algorithm          |
| -------------- | ------------------ |
| Regression     | Linear Regression  |
| Classification | Random Forest, SVM |
| NLP            | LSTM, Transformers |

---

### 5️ Model Evaluation

Choose metrics:

* Accuracy
* Precision/Recall
* RMSE

---

### 6️ Deployment Strategy

Plan where the model will run:

* Web app
* Cloud service
* API
